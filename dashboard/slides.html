The Problem 02 / 08
Why now

Per-call billing
has been impossible.

Developers want to charge $0.001 per inference. But on every existing chain, the economics collapse at the first transaction.

$0.001 call price — $2.40 Ethereum gas =
−$2.399 loss per call

Result: APIs resort to monthly invoicing. Agent-to-agent commerce stays off-ledger. The agentic economy can't exist at scale.

Where this goes

Stripe Connect for

Today: three models in a hackathon demo. Tomorrow: every LLM, image model, voice model, and code completion service lists itself on-chain.

const arcmeter = require("arcmeter");

// Wrap any handler → monetized endpoint
arcmeter.wrap(handler, {
  price: 0.001,         // USDC per call
  token: "USDC",
  chain: "arc-testnet",
  models: ["gemini", "ollama", "local"]
});
01
Every model becomes a paying endpoint. Any developer wraps their model in one line and starts earning USDC immediately.
02
Agent-to-agent commerce at scale. Buyers and sellers are both agents. Real programmable money, real settlements, real margins.
03
Settlements batch hourly. Reduce chain overhead further. Arc's sub-cent gas means batching is optional, not required.
04
Arc makes it possible. x402 makes it simple. Circle makes it accessible. This is the infrastructure layer for the agentic economy.
